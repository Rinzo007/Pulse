# Модель времени стоянки

Время стоянки является самостоятельной моделью, связывающей пассажирообмен, задержку и интервалы.

Базовая форма:

\[
Dwell=D_0+\alpha B+\beta A
\]

где D0 — базовое время стоянки, B — посадки, A — высадки, α и β — калибруемые параметры.

При необходимости учитываются двери, скорость посадки/высадки, доступность и ограничения подвижного состава:

\[
Dwell=D_0+\max(B/r_b,A/r_a,D_{door})
\]

Параметры не должны быть скрытыми константами.

Калибровка выполняется по наблюдаемому времени стоянки с независимой проверкой; результат связывается с типом подвижного состава, остановкой, временем суток и сценарием.
