# Выбор вида транспорта

Выбор вида транспорта преобразует характеристики доступных альтернатив в вероятности выбора или индивидуальный выбор.

## Базовая модель

$$P_i = e^{V_i}/Σ_j e^{V_j}$$

$$V_i = β_t T_i + β_w W_i + β_{tr} Tr_i + β_c C_i + β_r R_i + β_{crowd} Crowd_i + ASC_i$$

Знак и масштаб коэффициентов должны быть согласованы с определением полезности и единицами.

## Вложенная логит-модель

Для крупных моделей рекомендуется иерархическая структура, если альтернативы имеют коррелированные ненаблюдаемые компоненты. Структура дерева является параметром модели и должна быть обоснована данными.

## Требования

Фиксируются: набор альтернатив; availability каждой альтернативы; utility specification; коэффициенты; альтернативно-специфические константы; параметры вложенности; данные оценки; критерий качества; ограничения коэффициентов; версия модели.

Недоступная альтернатива не должна получать вероятность только из-за отсутствия данных о её стоимости.

## Калибровка

Используются наблюдаемые доли, обследования поездок, revealed preference, stated preference и агрегированные транспортные показатели. Нельзя подбирать коэффициенты только для совпадения одной общей доли, если модель должна воспроизводить временную и пространственную неоднородность.

## Чувствительность

Проверяется реакция долей на изменение времени поездки, ожидания, стоимости, числа пересадок, надёжности и переполнения. Малое изменение входа не должно вызывать необоснованно большое изменение выбора без соответствующей эластичности модели.
