# Выбор вида транспорта

## Общая идея

Для каждой допустимой альтернативы рассчитывается обобщённая стоимость поездки.

Минимальная базовая модель:

U_m = -C_m

Вероятность выбора при логит-модели:

P_m = exp(U_m) / Σ exp(U_k)

где сумма идёт по доступным альтернативам.

## Альтернативы

Минимально могут сравниваться:

- пешком;
- велосипед;
- автомобиль;
- общественный транспорт;
- P+R;
- B+R.

## Переменные

Модель может учитывать:

- время доступа;
- время ожидания;
- время в пути;
- число пересадок;
- тариф;
- стоимость автомобиля;
- парковку;
- надёжность;
- переполнение;
- комфорт;
- доступность.

## Калибровка

Коэффициенты должны настраиваться по наблюдаемым данным, если такие данные доступны.

Без калибровки результат является модельным сценарием, а не оценкой фактической доли рынка.

## Итерация

После симуляции качество ОТ может измениться. Поэтому допускается:

спрос → назначение → симуляция → новое время/надёжность → новый выбор → повтор.

Критерий остановки должен быть явным.
