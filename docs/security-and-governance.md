# Безопасность и управление моделью

## Разделение ролей

При зрелой реализации следует различать:

- просмотр данных;
- редактирование сети;
- создание сценариев;
- запуск расчётов;
- публикацию результатов;
- управление источниками.

## Аудит

Изменения критических параметров должны иметь автора, время, старое значение и новое значение.

## Публикация

Публичный отчёт должен явно указывать статус данных: реальные, синтетические, калиброванные или модельные.

## Ограничения

Модель не должна позволять незаметно изменить входные данные уже опубликованного результата.

## ИИ-помощник

ИИ может объяснять результаты и создавать предложения сценариев только на основании доступных расчётных данных и явных допущений. Он не должен придумывать отсутствующие наблюдения или выдавать рекомендацию за доказанный факт.
