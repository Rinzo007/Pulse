# Сбои и нештатные ситуации

Модель должна поддерживать не только идеальную эксплуатацию.

## События

- поломка транспортного средства;
- задержка;
- закрытие участка;
- авария;
- отсутствие водителя;
- нехватка транспорта;
- сбой зарядки;
- закрытие станции;
- пропуск рейса.

## Реакция

Сценарий может задавать:

- отмену;
- укороченный рейс;
- объезд;
- пересадку;
- резервный транспорт;
- изменение интервалов.

## KPI

Оцениваются:

- затронутые пассажиры;
- дополнительное время;
- пропущенные пересадки;
- устойчивость сети;
- время восстановления.
