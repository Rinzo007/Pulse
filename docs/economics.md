# Экономика

## CAPEX

Учитываются, если данные доступны:

- инфраструктура;
- остановки;
- депо;
- зарядная инфраструктура;
- светофорный приоритет;
- выделенные полосы;
- подвижной состав.

## OPEX

- водительский труд;
- энергия/топливо;
- обслуживание;
- выпуск;
- инфраструктурное обслуживание;
- прочие эксплуатационные расходы.

## Сравнение

Сценарий должен показывать стоимость вместе с транспортным эффектом.

Финансовая модель должна явно фиксировать валюту, базовый год, период расчёта, ставки и допущения.
