# Прогнозирование и будущие годы

Pulse должен различать:

- базовый год;
- прогнозный год;
- сценарий роста;
- сценарий изменения землепользования;
- сценарий изменения транспортного предложения.

## Изменения спроса

Могут меняться:

- население;
- занятость;
- места обучения;
- автомобилизация;
- цены;
- тарифы;
- частота поездок;
- пространственное распределение активностей.

## Индуцированный спрос

Если изменение транспортной доступности влияет на количество поездок, это должно быть отдельным механизмом модели, а не неявным предположением.

## Сравнение

Baseline и проектный прогноз должны использовать одинаковый горизонт и сопоставимые исходные допущения.
