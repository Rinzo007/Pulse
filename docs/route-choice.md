# Выбор маршрута

## Кандидаты

Для каждой поездки строится набор допустимых маршрутов и цепочек пересадок.

Кандидат должен учитывать:

- достижимость;
- время пешком;
- ожидание;
- время движения;
- пересадки;
- тариф;
- доступность;
- ограничения пассажира.

## Стоимость

Для цепочки r:

C_r = C_walk + C_wait + C_ride + C_transfer + C_fare + C_crowd + C_reliability

## Стохастический выбор

Если используется вероятностный выбор, вероятность каждого кандидата определяется моделью выбора маршрута.

## Ограничение

Нельзя использовать прямое географическое расстояние вместо сетевого времени там, где это меняет доступность маршрута.

## Переполнение

Если ожидаемая загрузка превышает вместимость, стоимость маршрута должна отражать вероятность отказа в посадке, необходимость ожидания следующего рейса или дискомфорт.
