# Оценивание параметров моделей

Калибровка начинается с определения параметров, которые действительно можно оценить по данным.

## Процесс

1. Определить наблюдаемые величины.
2. Определить параметры и границы.
3. Разделить данные для оценки и независимой проверки.
4. Задать целевую функцию.
5. Оценить параметры.
6. Проверить физический смысл.
7. Провести чувствительность.
8. Зафиксировать версию параметров.

## Целевая функция

Она должна быть определена до оценки и отражать соответствующие наблюдения, например ошибки потоков, времени, долей видов транспорта или ожидания.

## Защита от переобучения

Набор данных для независимой проверки не должен использоваться для подгонки параметров.

Результат оценивания должен иметь диапазон применимости и ограничения.
