# Приоритет общественного транспорта

Pulse должен оценивать не только пользу для ОТ, но и цену вмешательства для остальных участников.

## Инструменты

- выделенная полоса;
- запрет отдельных манёвров;
- светофорный приоритет;
- ранний зелёный;
- продление зелёного;
- координация светофоров;
- ограничения парковки;
- изменение фаз;
- локальные ограничения автомобильного движения.

## Оценка

Для каждого вмешательства сравниваются:

- время пассажиров ОТ;
- регулярность;
- задержка автомобилей;
- длина очередей;
- пропускная способность;
- безопасность при наличии данных;
- стоимость внедрения.

Нельзя считать вмешательство улучшением только потому, что ускорился автобус.
