# Методика калибровки

Калибровка настраивает параметры модели по независимым наблюдаемым данным.

## Цикл

1. определить наблюдаемую величину;
2. выбрать параметры;
3. выполнить расчёт;
4. измерить ошибку;
5. обновить параметры;
6. повторить;
7. проверить на данных, не использованных для настройки.

Целевая функция и ограничения должны быть зафиксированы.

Калибровка и валидация разделяются. Хорошее совпадение с данными калибровки не доказывает обобщаемость.

Параметры, полученные калибровкой, маркируются как калиброванные и имеют происхождение.
