# Тестирование

## Уровни

- Unit: формулы, выбор, время, вместимость, интервалы.
- Integration: база, PostGIS, экспорт и импорт.
- Simulation: маленькие сценарии с ожидаемым поведением.
- API: контракты и ошибки.
- Frontend: ключевые взаимодействия.
- End-to-end: город → спрос → ОТ → сценарий → симуляция → KPI → сравнение.

Тестовые данные включают маленький синтетический город и крайние случаи.
