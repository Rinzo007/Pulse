# Назначение спроса

Назначение распределяет поездки по доступным сетям и маршрутам с учётом ограничений модели.

## Входы

- OD;
- временной период;
- доступные режимы;
- сеть;
- транспортное предложение;
- generalized cost;
- ограничения вместимости;
- P+R/B+R;
- параметры выбора.

## Подходы

Допускаются:

- детерминированное назначение;
- вероятностное назначение;
- равновесное назначение;
- итеративное назначение с обратной связью.

Метод должен быть явно указан.

## Итерационный контур

Для моделей с обратной связью состояние системы обозначается `x`, а оператор назначения — `F`:

```math
x^{k+1}=F(x^k)
```

В состояние могут входить OD, доли видов транспорта, маршруты, нагрузки, ожидание и generalized cost.

Критерий сходимости задаётся явно. Минимально:

```math
||x^{k+1}-x^k|| < ε
```

При необходимости используется демпфирование:

```math
x^{k+1}=(1-λ)x^k+λF(x^k), 0<λ≤1
```

Для каждого запуска фиксируются `ε`, `λ`, максимальное число итераций и норма/метрика расстояния между состояниями.

## Отсутствие сходимости

Если критерий не достигнут до максимального числа итераций, результат маркируется как **не сошедшийся**. Нельзя выдавать последний итерационный шаг за равновесие без явного указания этого статуса.

Причина остановки, число итераций и остаточная ошибка сохраняются в результате.

## Валидация

Назначение не является доказательством наблюдаемого потока без калибровки и валидации. Проверяются как минимум объёмы, пространственное распределение и чувствительность к параметрам.
