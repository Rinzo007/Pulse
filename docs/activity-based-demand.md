# Модель спроса на основе активностей

## Цепочка

Генерация спроса должна по возможности описывать последовательность:

место → активность → место → следующая активность.

## Временные окна

Для каждой активности задаются:

- желательное начало;
- допустимое окно;
- длительность;
- обязательность или гибкость.

## Генерация

Спрос может строиться из:

- наблюдений;
- агрегированных статистических распределений;
- синтетической модели;
- сценарных допущений.

## Проверка

Суммарные поездки должны быть сопоставлены с доступными наблюдениями по времени, районам и целям.

## Обратная связь

Изменение доступности транспорта может менять время отправления, выбор вида транспорта и число поездок.
