# Планирование вычислительных экспериментов

## Повторяемость

Каждый эксперимент фиксирует:

- сценарий;
- seed;
- версии моделей;
- параметры;
- период;
- число повторов.

## Повторы

При наличии случайности один запуск не считается достаточным для сравнения сценариев.

## Парные эксперименты

Baseline и проектный сценарий по возможности запускаются на одинаковых случайных последовательностях, чтобы уменьшить шум сравнения.

## Статистика

Для KPI рекомендуется хранить:

- среднее;
- медиану;
- стандартное отклонение;
- квантили;
- доверительный интервал или другой заранее выбранный показатель неопределённости.

## Эффект

Помимо статистической разницы нужно показывать величину практического эффекта.
