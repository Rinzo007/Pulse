# Население и синтетические агенты

## Агент

Агент может иметь:

- возрастную группу;
- занятность;
- доступность автомобиля;
- доступность велосипеда;
- доступность общественного транспорта;
- ограничения мобильности;
- место проживания;
- места регулярных активностей;
- временные окна.

## Домохозяйство

Домохозяйство используется, когда совместные решения влияют на поездки и владение автомобилем.

## Синтетическое население

Генератор должен сохранять:

- seed;
- источники распределений;
- ограничения;
- правила генерации;
- версию генератора.

## Конфиденциальность

Если используются реальные микроданные, Pulse не должен требовать хранения персонально идентифицируемых данных для обычного моделирования.
