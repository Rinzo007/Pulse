# OpenStreetMap

OpenStreetMap может использоваться как источник дорожной, пешеходной, велосипедной и инфраструктурной геометрии.

## Конвейер

получение → сохранение исходных данных → преобразование → нормализация → проверка → построение модели Pulse.

Исходный набор не должен перезаписываться результатом преобразования.

## Проверки

Проверяются связность, направления, разрешённые режимы, геометрия, остановки, мосты, тоннели и пешеходная доступность.

Лицензия и атрибуция соблюдаются согласно условиям конкретного набора данных.
