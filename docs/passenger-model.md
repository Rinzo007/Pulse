# Модель пассажира

Полная поездка рассматривается как цепочка:

**дверь → пешком → остановка → ожидание → посадка → движение → высадка → пересадка → ожидание → следующий маршрут → высадка → пешком → дверь.**

Для каждого сегмента фиксируются время, расстояние, вид транспорта и причина задержки.

## Пересадки

Пересадка состоит минимум из:

1. высадки;
2. пешеходного перехода;
3. поиска платформы/остановки;
4. ожидания;
5. посадки.

Если между прибытием и отправлением недостаточно времени, пересадка считается пропущенной.

## Вместимость

Пассажир может:

- сесть сразу;
- ждать следующий рейс;
- отказаться от поездки;
- изменить маршрут.

Отказ в посадке увеличивает фактическое ожидание и может создавать обратную связь с загрузкой.

## Надёжность

Для поездок анализируются среднее, медиана, 80-й и 90-й процентили, вероятность опоздания и вероятность пропущенной пересадки.
