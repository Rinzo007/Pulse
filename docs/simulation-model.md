# Модель симуляции

## Роль SUMO

SUMO используется для микроскопического моделирования дорожного движения: автомобилей, автобусов, светофоров, очередей, конфликтов за дорожное пространство и задержек.

Pulse отвечает за:

- сценарий;
- спрос;
- маршруты;
- расписания;
- пассажирскую логику;
- эксплуатационную модель;
- интерпретацию результатов;
- сравнение сценариев.

## Цикл

1. Pulse формирует сценарий.
2. Сценарий экспортируется в формат SUMO.
3. Выполняется запуск.
4. Получаются траектории и агрегаты.
5. Pulse импортирует результаты.
6. Рассчитываются KPI.
7. При необходимости строится новый сценарий.

## Воспроизводимость

Запуск фиксирует версию сети, спроса, параметров, случайного зерна, конфигурации симуляции и версии модели.

## Отсутствие SUMO

Документация и проект должны позволять валидировать экспорт отдельно от запуска. Отсутствие установленного движка не должно превращать экспорт сценария в недействительный объект.
