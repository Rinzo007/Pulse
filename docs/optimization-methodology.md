# Методика оптимизации

Оптимизация начинается с явной постановки:

- переменные решения;
- целевая функция;
- ограничения;
- область допустимых решений;
- способ оценки кандидата;
- критерий остановки.

Целевая функция может учитывать пассажирское время, ожидание, надёжность, переполнение, OPEX, CAPEX и влияние на автомобильное движение.

Эвристический поиск, локальный поиск и алгоритмические кандидаты не называются доказанным глобальным оптимумом без соответствующего основания.

Каждый кандидат должен сохранять входы, параметры, ограничения, результат и версию метода.
