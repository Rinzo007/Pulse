# Модель транспортной сети

## Дорожная сеть

Минимальное описание ребра:

- начало и конец;
- длина;
- направление;
- число полос;
- разрешённые виды транспорта;
- ограничение скорости;
- тип дороги;
- правила поворота;
- светофорное управление;
- ограничения для ОТ.

Сеть должна быть ориентированной там, где направление движения различается.

## Пешеходная сеть

Для каждой связи нужны длина, доступность, уклон при наличии данных, разрешённость прохода и связь с остановками.

Реальное время пересадки рассчитывается по пешеходной сети, а не по прямому расстоянию.

## Велосипедная сеть

Учитываются велодорожки, смешанное движение, запреты, пересечения и возможность B+R.

## Транзитная инфраструктура

Для трамвая, метро и железной дороги должна существовать отдельная инфраструктурная модель с линиями, станциями, платформами и ограничениями.

## Проверки

- оборванные рёбра;
- недостижимые узлы;
- самопересечения;
- невозможные повороты;
- остановки вне доступной сети;
- маршруты, проходящие по запрещённой инфраструктуре;
- несогласованные направления.
