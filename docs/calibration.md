# Калибровка

Калибровка — процесс настройки модели по наблюдаемым данным.

## Цикл

**наблюдение → модель → ошибка → изменение параметров → повторный запуск → проверка на независимых данных.**

## Что калибруется

В зависимости от данных:

- интенсивности движения;
- времена движения;
- распределение времени ожидания;
- пассажиропотоки;
- выбор вида транспорта;
- стоянки;
- надёжность;
- параметры спроса.

## Ограничение

Синтетический город без наблюдений может быть проверен на внутреннюю физическую согласованность, но не должен называться калиброванным реальным городом.
