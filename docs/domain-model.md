# Предметная модель

## Основные объекты

**City** — границы и базовые характеристики территории.

**TransportZone** — зона спроса с населением, рабочими местами, услугами и связями с соседними зонами.

**RoadNode / RoadEdge** — топологическая дорожная сеть.

**PedestrianEdge / CyclingEdge** — сети немоторизованных перемещений.

**Stop / Platform** — место посадки и высадки.

**Route** — логический маршрут ОТ.

**RoutePattern** — конкретная трассировка маршрута по инфраструктуре.

**Trip** — отдельный рейс с временем отправления и последовательностью остановок.

**Vehicle** — единица подвижного состава с типом, вместимостью и ограничениями.

**Depot** — место хранения, выпуска, возврата и обслуживания.

**ODMatrix** — спрос между транспортными районами по времени и цели поездки.

**PassengerTrip** — индивидуальная или агрегированная цепочка поездки.

**Scenario** — неизменяемая версия исходного состояния плюс набор вмешательств.

**SimulationRun** — конкретный запуск модели.

**KPISet** — набор измеренных показателей запуска.

## Связи

Город содержит зоны и сети. Зоны порождают спрос. Спрос выбирает цепочки поездок. Цепочка использует пешеходную, автомобильную и/или транзитную сеть. Маршруты состоят из вариантов трассировки и рейсов. Рейсы используют транспорт и обслуживаются депо. Сценарий фиксирует версии всех входов. Запуск симуляции производит измерения, из которых строятся KPI.

## Идентичность

Каждая сущность должна иметь стабильный идентификатор. Исторические версии не должны молча изменять результаты уже выполненного сценария.
