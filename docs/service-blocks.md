# Блоки движения и эксплуатационная выполнимость

Расписание считается эксплуатационно выполнимым только при наличии физически согласованных блоков движения.

## Блок

Блок связывает последовательность рейсов одной единицы подвижного состава: Depot → Trip 1 → Trip 2 → … → Trip N → Depot.

Для каждого перехода проверяются место окончания предыдущего рейса, место начала следующего, время прибытия, время отправления, минимальный оборот, технологический резерв, тип транспортного средства и зарядка, если применима.

## Цикл линии

$$CycleTime = Runtime_{out}+Layover_{terminal1}+Runtime_{back}+Layover_{terminal2}$$

$$N_{vehicles}=ceil(CycleTime/Headway)$$

Эта формула является нижней оценкой и не заменяет проверку фактических блоков.

## Дополнительные ограничения

Проверяются сменность экипажей, перерывы, рабочее время, резервный парк, зарядка электробусов, депо, совместимость типов подвижного состава и физическая возможность перехода между рейсами.

## Результат

Планировщик возвращает статус: выполним, выполним с резервом или невыполним. Для невыполнимого блока указывается причина и конкретное ограничение.
