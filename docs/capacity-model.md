# Модель провозной способности

## Вместимость

Для транспортного средства:

Capacity = seated + standing

При наличии ограничений доступности или эксплуатационных правил допустимая вместимость может быть меньше физической.

## Состав

Для нескольких единиц:

Capacity_train = Σ Capacity_vehicle

## Динамическая загрузка

Для каждого рейса и межостановочного участка:

Load_after = Load_before + boardings - alightings

Должно выполняться:

0 ≤ Load_after ≤ допустимая вместимость

Если Load_after превышает допустимую вместимость, возникает отказ в посадке.

## Отказ в посадке

Непринятые пассажиры остаются на остановке и переносятся на последующие рейсы согласно правилам модели.

Это создаёт обратную связь:

переполнение → ожидание → больше пассажиров на следующем рейсе → новое переполнение.

## Пиковая нагрузка

Для маршрута фиксируется максимальная нагрузка по участкам и время её возникновения.
