# Модель провозной способности

Провозная способность различает физическую вместимость, эксплуатационно допустимую и фактически доступную пассажиру.

## Уровни

PhysicalCapacity → OperationalCapacity → EffectiveCapacity → AvailableCapacity.

**PhysicalCapacity** — физический предел транспортного средства.

**OperationalCapacity** — предел с учётом комфорта, безопасности и эксплуатации.

**EffectiveCapacity** — практическая способность перевозить пассажиров с учётом стоячей плотности, дверей, скорости посадки/высадки, проходов, состава пассажиров, доступности и эксплуатационной политики.

## Динамическая загрузка

$$Load_s = Passengers_s / AvailableCapacity_s$$

Если доступная вместимость меняется по сегментам, нельзя использовать только максимальную вместимость транспортного средства.

## Отказ в посадке

$$DeniedBoarding = max(0, Demand_{board} - AvailableSpace)$$

Отказавшийся пассажир остаётся в модели и переносит спрос на следующие доступные отправления согласно правилам пассажирской модели.

## Комфорт

Отдельно фиксируются физическое переполнение, превышение комфортного порога, отказ в посадке и накопленное ожидание.

## Калибровка

Параметры эффективной вместимости и скоростей пассажирообмена калибруются по данным эксплуатации, APC/наблюдениям и данным о стоянках и дверях, если они доступны.
