# Качество обслуживания

Качество ОТ должно оцениваться не только временем поездки.

## Компоненты

- ожидание;
- регулярность;
- надёжность;
- переполнение;
- вероятность отказа в посадке;
- пересадки;
- доступность информации;
- доступность для маломобильных пассажиров.

## Разрезы

Показатели следует рассчитывать по:

- маршруту;
- времени;
- зоне;
- виду транспорта;
- типу пассажира;
- сценарию.

Среднее значение не должно скрывать локальные провалы качества.
