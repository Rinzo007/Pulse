# Сравнение сценариев

Сценарии сравниваются только при сопоставимых:

- периодах;
- версиях исходных данных;
- сетях;
- параметрах модели;
- правилах расчёта;
- случайных последовательностях или схеме репликаций;
- критериях оценки.

## Результаты

Для каждого KPI показываются:

- baseline;
- проект;
- абсолютное изменение;
- относительное изменение;
- разброс при наличии репликаций;
- неопределённость;
- применимые ограничения.

При paired-экспериментах baseline и проект используют согласованные случайные последовательности.

Различие средних само по себе не означает статистически или практически значимого улучшения.
