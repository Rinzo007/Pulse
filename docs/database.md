# Модель данных

Основные таблицы: transport_zones, road_nodes, road_edges, stops, routes, route_patterns, trips, vehicles, depots, od_matrices, passenger_trips, scenarios, simulation_runs, kpis.

PostGIS используется для геометрии и пространственных индексов.

Исторические сценарии и запуски должны ссылаться на версии входных сущностей. Нельзя незаметно изменять данные, от которых зависит старый результат.

Индексы проектируются под пространственный поиск, соседей, маршруты, временные диапазоны, сценарии и запуски.
