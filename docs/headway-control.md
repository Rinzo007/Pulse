# Управление интервалами

## Цель

Управление интервалом стремится уменьшить отклонение фактических интервалов от целевого.

Для последовательных рейсов:

h_i = departure_i - departure_(i-1)

Ошибка интервала:

e_i = h_i - h_target

## Механизмы

- удержание на остановке;
- изменение времени отправления;
- диспетчерское регулирование;
- временное укорочение/продление оборота;
- изменение выпуска.

## Ограничения

Управление не должно нарушать:

- допустимое время ожидания;
- оборот;
- рабочие ограничения;
- вместимость;
- технологические окна.

## Оценка

Сравниваются распределения интервалов, пассажирское ожидание, задержка и стабильность движения.

Улучшение среднего интервала не считается достаточным, если одновременно растёт его разброс.
