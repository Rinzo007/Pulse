# Планирование маршрутов

## Построение

Новый маршрут должен оцениваться по:

- покрытию спроса;
- времени доступа;
- прямоте поездки;
- числу пересадок;
- провозной способности;
- взаимодействию с существующей сетью;
- эксплуатационной стоимости;
- доступности депо.

## Маршрут и вариант трассировки

Логический маршрут не равен единственной геометрии. Один маршрут может иметь варианты трассировки, укороченные рейсы, экспрессы и разные режимы обслуживания.

## Рекомендации

Автоматическая рекомендация должна содержать:

- обнаруженную проблему;
- исходные показатели;
- предлагаемое изменение;
- ожидаемый эффект;
- стоимость;
- риски;
- показатели, которые нужно проверить;
- статус «предложение», а не «оптимальное решение», пока результат не проверен.
