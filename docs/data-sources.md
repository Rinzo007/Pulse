# Источники данных

Для каждого набора данных хранить:

- источник;
- URL или идентификатор;
- дату получения;
- версию;
- лицензию;
- географическое покрытие;
- временной период;
- преобразования;
- качество;
- ограничения использования.

Источники нельзя смешивать так, чтобы происхождение отдельных значений становилось неизвестным.

## Нормативная иерархия происхождения

Для выбора **входного значения**, когда несколько источников дают конкурирующие значения, Pulse использует следующую нормативную иерархию:

1. официальные или иные проверенные внешние данные;
2. наблюдаемые данные;
3. калиброванные параметры;
4. производные расчётные данные;
5. синтетические данные;
6. явно заданные модельные допущения.

Эта иерархия определяет не безусловную «истинность» источника, а порядок доверия при формировании модельного входа. Она не отменяет проверки актуальности, географии, периода, методики измерения, качества и совместимости данных.

### Правила разрешения конфликтов

Если наблюдение противоречит официальному набору данных, нельзя автоматически считать одно из значений истинным только по типу источника. Сначала проверяются:

- временной период;
- география и пространственная детализация;
- определение показателя;
- методика измерения;
- полнота и репрезентативность;
- дата обновления;
- качество и ограничения;
- возможность того, что источники измеряют разные аспекты одного показателя.

Если после проверки конфликт сохраняется, для **базового модельного входа** применяется более высокий уровень иерархии, а конфликт, альтернативное значение и причина выбора фиксируются в происхождении данных. Наблюдение при этом не удаляется и может использоваться для валидации, чувствительности или отдельного сценария.

### Калиброванные и производные данные

- **Калиброванный параметр** — параметр модели, оценённый по наблюдениям в рамках процедуры калибровки. Он не является внешним наблюдением и не заменяет исходные данные.
- **Производное расчётное значение** — значение, вычисленное из других входов по зафиксированному правилу или модели. Оно не должно автоматически иметь больший приоритет, чем исходные данные, из которых получено.
- **Расчётный результат** — результат выполнения модели для конкретного сценария; это не входной источник истины для другого сценария без явного основания.

Иерархия источников должна быть согласована с таксономией [assumptions.md](assumptions.md).

Синтетические значения всегда маркируются как синтетические.
