# Источники данных

Для каждого набора данных хранить:

- источник;
- URL или идентификатор;
- дату получения;
- версию;
- лицензию;
- географическое покрытие;
- временной период;
- преобразования;
- качество;
- ограничения использования.

Источники нельзя смешивать так, чтобы происхождение отдельных значений становилось неизвестным.

## Приоритет

1. официальные открытые данные;
2. проверенные открытые геоданные;
3. наблюдения;
4. синтетические данные при отсутствии наблюдений;
5. модельные допущения.

Синтетические значения всегда маркируются как синтетические.
