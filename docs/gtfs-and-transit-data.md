# Форматы данных общественного транспорта

## GTFS

Для регулярного общественного транспорта должна быть предусмотрена поддержка импорта и экспорта GTFS, включая как минимум:

- остановки;
- маршруты;
- варианты трассировки;
- рейсы;
- расписания;
- календарь;
- последовательность остановок.

## Расширения

GTFS не заменяет внутреннюю модель Pulse. Для симуляции могут понадобиться:

- фактические времена;
- вместимость;
- состав;
- платформа;
- задержки;
- интервалы;
- информация о пересадках;
- эксплуатационные ограничения.

## Происхождение

Каждый импорт фиксирует источник, дату, версию, период действия и преобразования.

## Экспорт

Экспортированная транспортная сеть должна быть проверена на связность маршрутов, корректность времени и последовательность остановок.
