# Модель сбивания интервалов

## Механизм

Задержка → больше пассажиров на остановке → больше посадок → больше стоянка → увеличение задержки → приближение следующего рейса.

## Стоянка

Минимальная модель стоянки должна связывать пассажирообмен с длительностью остановки:

```math
Dwell = D_0 + αB + βA
```

где `B` — посадки, `A` — высадки, `D_0` — базовая стоянка.

Для моделей с ограничением пропускной способности дверей допускается форма:

```math
Dwell = D_0 + max(B/r_b, A/r_a, D_door)
```

Параметры должны иметь физический смысл, единицы, происхождение и калибровку.

## Показатели

Для маршрута:

- средний интервал;
- стандартное отклонение;
- коэффициент вариации;
- доля слишком малых интервалов;
- доля слишком больших интервалов;
- доля рейсов, попавших в bunching.

## Критерий

Порог bunching должен быть параметром сценария. Единицы и базовый интервал должны быть зафиксированы.

## Замкнутая связь

Модель должна позволять проверять цепочку:

```text
Passengers → Dwell → Delay → Headway → Waiting → PassengerLoad
```

Это не просто набор KPI: изменение пассажиропотока должно через стоянку иметь возможность изменить движение и последующее ожидание.

## Проверка

Модель должна различать естественную вариативность движения и устойчивое сбивание интервалов.

## Вмешательства

Могут проверяться удержание, приоритет ОТ, изменение расписания, дополнительный выпуск и изменение трассировки.
