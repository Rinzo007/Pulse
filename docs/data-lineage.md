# Происхождение данных

Pulse должен позволять проследить происхождение каждого набора и каждого результата.

## Цепочка

Источник → исходный набор → нормализация → производный набор → сценарий → запуск → KPI → отчёт.

## Метаданные набора

Минимально:

- идентификатор;
- название;
- источник;
- дата получения;
- период данных;
- версия;
- лицензия;
- география;
- единицы;
- система координат;
- преобразования;
- качество;
- ограничения.

## Производные данные

Производный набор хранит ссылки на исходные наборы и описание преобразования.

## Результаты

SimulationRun и KPI должны ссылаться на версии входных данных и параметров, из которых они получены.

Удаление или замена источника не должно уничтожать возможность объяснить старый результат.
