# Формулы доступности

Для зоны или агента доступность оценивается через достижимые возможности при ограничении общего времени.

Для возможности j:

A_j(T)=I(t_ij <= T)

где t_ij — сетевое время доступа от i до j, а T — заданный порог.

Агрегированная доступность:

A_i(T)=Σ_j W_j I(t_ij <= T)

где W_j — вес возможности, например население, рабочие места или количество мест обслуживания.

## Общее время

t_ij должно включать релевантные компоненты цепочки поездки: доступ, ожидание, движение, пересадки и выход.

Пороговые значения 15/30/45/60 минут задаются явно. Расстояние по прямой не заменяет сетевое время.

Результат всегда должен ссылаться на сценарий, период и версию сети.
