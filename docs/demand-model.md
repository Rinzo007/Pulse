# Модель транспортного спроса

## Синтетическое население

Агент должен иметь только необходимые для моделирования свойства: зона проживания, зоны активности, временные предпочтения, доступность автомобиля/велосипеда и ограничения мобильности.

## Поездки

Для каждой поездки задаются:

- начало;
- конец;
- цель;
- желаемое временное окно;
- продолжительность активности;
- допустимые виды транспорта.

## OD

OD-матрица хранит объём поездок между зонами по временным интервалам и, при необходимости, по целям.

## Выбор вида транспорта

Обобщённая стоимость может включать:

- время пешком;
- ожидание;
- время в транспортном средстве;
- пересадки;
- денежную стоимость;
- надёжность;
- переполнение;
- комфорт;
- доступность.

Коэффициенты должны быть параметрами модели, а не скрытыми константами.

## Динамический спрос

Изменение качества ОТ может изменить выбор вида транспорта. Поэтому для крупных сценариев допускается итерационный цикл:

спрос → назначение → симуляция → качество → новый выбор → повторная симуляция.

Сходимость должна быть измеримой.
