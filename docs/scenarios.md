# Сценарии

Сценарий — неизменяемая версия входного состояния и набора изменений.

## Baseline

Базовый сценарий описывает исходную сеть, спрос, парк, расписания и правила.

## Интервенция

Интервенция может менять:

- инфраструктуру;
- маршрут;
- остановки;
- интервалы;
- тип подвижного состава;
- приоритет ОТ;
- тариф;
- парковку;
- P+R/B+R;
- режимы движения.

## Сравнение

Сценарии сравниваются при максимально одинаковых условиях: период, спрос, случайные зерна и критерии оценки.

## Версионирование

Нельзя незаметно менять входные данные уже завершённого запуска. Любое существенное изменение создаёт новую версию.
