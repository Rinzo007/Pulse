# Неопределённость

Транспортная модель содержит неопределённость спроса, времени движения, поведения пассажиров, вместимости и внешних условий.

## Уровни

1. Неопределённость входных данных.
2. Неопределённость параметров.
3. Случайность поведения.
4. Вариативность дорожного движения.
5. Неопределённость проектного решения.

## Многократные запуски

Для чувствительных сценариев выполняется серия запусков с разными случайными зернами или параметрами.

Отчёт должен показывать:

- число запусков;
- среднее;
- медиану;
- квантили;
- разброс;
- вероятность достижения заданного порога.

## Сравнение

Если два сценария имеют пересекающиеся распределения результатов, система не должна автоматически объявлять один вариант безусловно лучшим.

## Чувствительность

Для ключевых параметров можно вычислять влияние изменения параметра на KPI. Это помогает отличить устойчивый вывод от результата, зависящего от одного спорного допущения.
