# Парковка, P+R и B+R

## Парковка

Модель может учитывать:

- расположение;
- вместимость;
- тариф;
- режим работы;
- вероятность найти место;
- ограничения по времени.

## P+R

Цепочка:

дом → автомобиль → парковка → ОТ → пункт назначения.

Стоимость включает автомобильный участок, парковку, пересадку и общественный транспорт.

## B+R

Цепочка:

дом → велосипед → парковка → ОТ → пункт назначения.

## Конкуренция

Изменение парковки или тарифа может менять выбор вида транспорта и загруженность дорог и ОТ.
