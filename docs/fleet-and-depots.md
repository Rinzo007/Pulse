# Подвижной состав и депо

## Подвижной состав

Для типа транспортного средства задаются:

- вместимость;
- стоячие и сидячие места;
- длина;
- максимальная скорость;
- ускорение/торможение при необходимости;
- потребление энергии;
- доступность;
- ограничения инфраструктуры.

## Электробусы

Дополнительно:

- ёмкость батареи;
- начальный заряд;
- расход;
- минимальный резерв;
- зарядные окна;
- тип зарядки;
- время зарядки.

## Депо

Депо имеет:

- географическое положение;
- вместимость;
- совместимые типы транспорта;
- выпуск;
- возврат;
- обслуживание;
- зарядные места.

План выпуска должен проверяться на достижимость маршрутов и временную выполнимость.
