# Оптимизация

Оптимизация может применяться к маршрутам, интервалам, расписаниям, выпуску, приоритету и инфраструктуре.

## Целевая функция

Обычно используется многокритериальная функция, например:

- минимизация времени пассажиров;
- минимизация ожидания;
- минимизация эксплуатационных затрат;
- ограничение перегрузки;
- ограничение задержки автомобилей;
- ограничение капитальных затрат.

## Ограничения

Решение обязано соблюдать:

- физическую связность;
- вместимость;
- доступность депо;
- оборот;
- рабочие ограничения;
- совместимость транспорта и инфраструктуры;
- бюджет.

## Статус результата

Эвристический или найденный алгоритмом вариант называется кандидатом. Термин «оптимальный» используется только при явно указанной постановке, методе, ограничениях и критерии оптимальности.
