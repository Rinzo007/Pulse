# Network Health Check

Network Health Check — автоматический диагностический слой Pulse.

## Что проверяется

### Покрытие
- районы без доступного ОТ;
- длинные подходы к остановкам;
- отсутствующие связи между районами.

### Маршруты
- перегруженные участки;
- недогруженные участки;
- слишком длинные маршруты;
- чрезмерное число пересадок;
- низкая надёжность.

### Пересадки
- длинные пешеходные связи;
- пропущенные пересадки;
- несогласованные интервалы.

### Эксплуатация
- нехватка выпуска;
- невозможный оборот;
- проблемы депо;
- зарядная инфраструктура.

### Движение
- задержки;
- очереди;
- участки с повторяющимся bunching;
- конфликт ОТ и автомобильного движения.

## Рекомендация

Каждая найденная проблема должна иметь:

1. идентификатор;
2. географию;
3. показатель;
4. порог;
5. причину;
6. возможные вмешательства;
7. ожидаемые эффекты;
8. стоимость при наличии данных;
9. риски;
10. необходимость симуляционной проверки.

Диагностика не создаёт автоматически утверждённый проект.
