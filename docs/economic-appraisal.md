# Экономическая оценка

CAPEX и OPEX недостаточны для полноценной оценки проекта.

## Выгоды

При наличии необходимых данных могут учитываться:

- экономия времени;
- снижение задержек;
- изменение эксплуатационных затрат;
- изменение аварийных рисков;
- изменение выбросов;
- изменение пользовательских расходов.

## Дисконтирование

Для многолетнего сценария должны быть заданы:

- базовый год;
- горизонт;
- ставка дисконтирования;
- периодичность потоков;
- инфляционные предположения.

## Результаты

Допускаются NPV, BCR и срок окупаемости, но только при явно заданной методике и денежных коэффициентах.

Модельные KPI сами по себе не являются экономической оценкой.
