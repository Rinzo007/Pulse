# Пешеходная и велосипедная модели

## Пешеходная сеть

Учитываются:

- тротуары;
- переходы;
- лестницы;
- барьеры;
- светофоры;
- доступность;
- уклоны;
- реальные сетевые расстояния.

## Велосипедная сеть

Учитываются:

- велодорожки;
- полосы;
- совместное движение;
- ограничения;
- уклоны;
- пересечения;
- скорость.

## Пересадки

Пешеходное перемещение между остановками и платформами считается по сети, а не по прямой.

## Доступность

Для пользователей с ограниченной мобильностью может существовать отдельный граф доступных связей.
