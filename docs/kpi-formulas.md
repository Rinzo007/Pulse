# Формулы KPI

Каждый KPI имеет полный контракт:

```text
Definition + Formula + Unit + Period + Population + Aggregation + Source + Uncertainty
```

## Обязательные поля

Для каждого показателя фиксируются:

- определение;
- формула;
- единица;
- период наблюдения/расчёта;
- пространственный охват;
- совокупность пассажиров, рейсов или участков;
- способ агрегации;
- источник данных;
- версия входов;
- неопределённость;
- статус калибровки/валидации.

## Среднее время

```math
T_avg = (1/N) Σ_i T_i
```

## Изменение

```math
ΔK = K_project - K_baseline
```

```math
ΔK% = 100 × (K_project - K_baseline) / K_baseline
```

Если baseline равен нулю, относительное изменение не вычисляется по этой формуле и должен быть указан альтернативный способ представления.

## Загрузка

```math
Load = Passengers / AvailableCapacity
```

Определение `AvailableCapacity` должно соответствовать [capacity-model.md](capacity-model.md); физическая вместимость и эксплуатационно допустимая вместимость не смешиваются.

## Коэффициент вариации интервала

```math
CV_h = SD(h) / mean(h)
```

## Доступность

Используются формулы из [accessibility-formulas.md](accessibility-formulas.md).

## Сравнимость

Нельзя сравнивать KPI с разными определениями, периодами, пространственным охватом, совокупностями или входными версиями.

Результат KPI не должен скрывать разброс и неопределённость одним средним значением.
