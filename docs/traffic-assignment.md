# Назначение транспортного спроса

## Назначение

Спрос переводится из OD-матриц в конкретные маршруты и транспортные сети.

## Подход

Для простого сценария допускается детерминированное назначение по минимальной обобщённой стоимости.

Для более зрелой модели допускается вероятностное или равновесное назначение.

## Ограничения

Назначение должно учитывать:

- пропускную способность;
- временные окна;
- допустимые виды транспорта;
- пересадки;
- доступность;
- P+R/B+R.

## Итерационное назначение

При наличии перегрузки:

спрос → назначение → загрузка → изменение стоимости → новое назначение.

Критерий сходимости должен быть задан заранее.

## Результат

Результатом являются потоки по OD, сети, маршрутам и временным интервалам.
