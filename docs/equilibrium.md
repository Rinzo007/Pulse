# Равновесие спроса и предложения

Итеративная модель описывается как:

\[
x^{k+1}=F(x^k)
\]

где x включает применимые компоненты спроса, назначения, загрузки, обобщённой стоимости и качества обслуживания.

При необходимости применяется демпфирование:

\[
x^{k+1}=(1-\lambda)x^k+\lambda F(x^k),\quad 0<\lambda\le1
\]

Критерии сходимости задаются до запуска. Минимально контролируются относительные изменения потоков, долей видов транспорта, загрузки ОТ и обобщённой стоимости.

Для MVP рекомендуются ориентиры: доля вида транспорта < 0,5 процентного пункта, потоки < 2%, загрузка ОТ < 2%, обобщённая стоимость < 1%. Пороги являются параметрами запуска.

Фиксируются максимальное число итераций и поведение при отсутствии сходимости. Несошедшийся расчёт не маркируется как валидное равновесие.
