# Равновесие спроса и предложения

Итеративная транспортная модель описывается как:

\[
x^{k+1}=F(x^k)
\]

где состояние x включает применимые компоненты спроса, назначения, загрузки, обобщённой стоимости и качества обслуживания.

## Демпфирование

При необходимости используется:

\[
x^{k+1}=(1-\lambda)x^k+\lambda F(x^k),\quad 0<\lambda\le1
\]

Значение λ фиксируется параметрами запуска.

## Сходимость

Запуск считается сошедшимся только при выполнении заранее заданных критериев. Минимально проверяются относительные изменения:

- потоков;
- долей видов транспорта;
- загрузки ОТ;
- обобщённой стоимости.

Пример допустимых критериев для MVP:

- доля вида транспорта: < 0.5 процентного пункта;
- потоки: < 2%;
- загрузка ОТ: < 2%;
- обобщённая стоимость: < 1%.

Порог должен быть конфигурационным параметром, а не скрытой константой.

## Остановка

Также задаются максимальное число итераций и поведение при отсутствии сходимости. Несошедшийся расчёт не должен маркироваться как валидный результат равновесия.
