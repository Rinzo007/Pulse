# Модель надёжности

Надёжность ОТ оценивается распределением фактического времени движения, ожидания, интервалов и пересадок, а не только средним значением.

Для времени поездки и ожидания при наличии данных рассчитываются P50, P80, P90, P95, среднее и показатель разброса.

Буфер:

\[
Buffer_p=Q_p(T)-Median(T)
\]

где Qp — выбранный процентиль.

Вероятность успешной пересадки рассчитывается из распределений фактического прибытия первого сегмента и отправления второго с учётом времени пешего перемещения и заданного буфера.

Среднее без распределения не считается достаточной оценкой надёжности.
