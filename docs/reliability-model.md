# Модель надёжности

Надёжность описывает распределение фактического времени движения, прибытия, отправления и пересадки, а не только среднее время.

## Показатели

Хранятся как минимум P50, P80, P90, P95, среднее и стандартное отклонение. Квантили рассчитываются по явно указанной совокупности и периоду.

## Опоздание

$$Delay = T_{actual} - T_{scheduled}$$

Определение различает раннее прибытие, опоздание, раннее отправление и вынужденное удержание.

## Buffer time

Одно из возможных определений:

$$BT_{90}=P90(T)-P50(T)$$

Используемое определение фиксируется в KPI-контракте.

## Пересадка

$$P(A_2 ≥ A_1+t_{walk}+t_{buffer})$$

Пропущенная пересадка должна порождать последующее ожидание, а не просто увеличивать один KPI.

## Сравнение

Нельзя считать улучшением уменьшение среднего времени при одновременном ухудшении P90/P95 без явного отражения компромисса.
