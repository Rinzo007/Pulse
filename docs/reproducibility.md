# Воспроизводимость

Каждый расчёт должен быть восстановим из версии кода, версии данных, версии сценария, параметров, случайного зерна, конфигурации симуляции и версии движка.

При одинаковых входах допустимые численные расхождения должны быть известны и документированы.

Результат хранит происхождение: кто или что его создало, когда, из какого сценария и с какими параметрами.
