# Математическая спецификация

Этот документ фиксирует базовые математические определения Pulse. Конкретные параметры являются настраиваемыми и должны иметь источник или статус допущения.

## 1. Общее время поездки

Для пассажира:

T = T_walk_access + T_wait + T_ride + T_transfer + T_walk_egress + T_delay

где T_transfer включает пешеходное перемещение между платформами и ожидание следующего рейса.

## 2. Обобщённая стоимость

Базовая форма:

C = β_walk T_walk + β_wait T_wait + β_ride T_ride + β_transfer N_transfer + β_fare F + β_crowd C_crowd + β_reliability R

Коэффициенты β не должны быть скрытыми константами.

## 3. Надёжность

Для времени поездки случайной величины T используются среднее, медиана, 80-й и 90-й процентили.

Вероятность опоздания относительно порога τ:

P_late = P(T > τ)

## 4. Загрузка

Для участка e и момента t:

Load(e,t) = число пассажиров, находящихся в транспортном средстве на участке.

Коэффициент загрузки:

LoadRatio = Load / Capacity

Перегрузка определяется относительно явно заданного порога.

## 5. Ожидание

Для случайного прибытия пассажира при регулярном интервале h:

E[T_wait] ≈ h / 2

Для нерегулярного движения расчёт должен использовать фактическое распределение интервалов.

## 6. Доступность

Для зоны i и цели j:

Accessible(i,j,τ) = 1, если существует допустимая цепочка поездки с T ≤ τ.

Доступность населения:

A(τ) = сумма населения зон, для которых условие выполнено.

## 7. Сравнение сценариев

Для KPI K:

ΔK = K_project - K_baseline

Относительное изменение:

ΔK% = 100 · ΔK / K_baseline

Знак интерпретируется с учётом направления полезности KPI.
