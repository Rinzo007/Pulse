# Модель ожидания

Ожидание определяется относительно фактического или моделируемого распределения прибытия пассажира и отправлений.

При равномерном случайном прибытии и регулярном интервале h:

E[W] = h / 2.

Для нерегулярных интервалов среднее ожидание не следует автоматически считать равным половине среднего интервала. Используется распределение интервалов и выбранная модель прибытия пассажиров.

Для запланированного прибытия пассажира:

W = max(0, departure - arrival).

При пересадке ожидание учитывает фактическое прибытие предыдущего сегмента и доступное следующее отправление. Пропущенная пересадка моделируется отдельно.

Все результаты должны указывать модель прибытия пассажира и источник расписания.
