# Глоссарий

**Транспортный район** — пространственная единица моделирования спроса.

**OD-матрица** — объёмы поездок между зонами отправления и назначения.

**Маршрут** — логическая услуга общественного транспорта.

**Вариант трассировки** — конкретный путь маршрута по инфраструктуре.

**Рейс** — отдельное выполнение маршрута в заданное время.

**Интервал движения** — время между последовательными рейсами.

**Сбивание интервалов (bunching)** — накопление рейсов из-за задержек и взаимодействия с пассажиропотоком.

**Доступность** — возможность достичь целей за заданное общее время.

**P+R** — перехватывающая парковка «автомобиль + общественный транспорт».

**B+R** — велоперехватывающая парковка «велосипед + общественный транспорт».

**CAPEX** — капитальные затраты.

**OPEX** — эксплуатационные затраты.

**Сценарий** — версия модели с фиксированными входами и набором вмешательств.

**Калибровка** — настройка параметров по наблюдаемым данным.

**Валидация** — проверка модели на данных или свойствах, не использованных для настройки.

**Микроскопическая симуляция** — моделирование отдельных транспортных средств и их взаимодействий.
