# Допущения и политика модели

Этот документ задаёт правила, по которым Pulse должен отличать факт, наблюдение, допущение и расчёт.

## Категории

- **Наблюдение** — значение, полученное из внешнего источника.
- **Производное значение** — вычислено из наблюдений или других входов.
- **Синтетическое значение** — создано генератором модели.
- **Допущение** — задано проектировщиком при отсутствии данных.
- **Калиброванный параметр** — настроен по наблюдениям.
- **Расчётный результат** — получен моделью.
- **Рекомендация** — предложение алгоритма или аналитика, требующее проверки.

## Правила

Каждый значимый вход должен иметь происхождение и единицы измерения.

Если значение неизвестно, система не должна молча подставлять реалистично выглядящее число. Должно быть указано, что именно было допущено.

Синтетический город и синтетический спрос могут использоваться для разработки, тестирования и демонстрации, но не являются доказательством поведения реального города.

## Неопределённость

Для важных параметров допускаются диапазоны и распределения. Результаты сценария могут представляться как диапазон, квантиль или распределение, а не только одним числом.

## Ограничение интерпретации

Результат модели отвечает на вопрос «что показывает заданная модель при заданных входах», а не автоматически на вопрос «что произойдёт в реальности».
