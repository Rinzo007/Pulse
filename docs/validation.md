# Проверка модели

## Физическая реалистичность

Автоматически выявляются отрицательные времена, невозможные скорости, движение по запрещённому ребру, пассажиры без доступного пути, отрицательная вместимость, невозможный оборот и зарядка вне доступного депо.

## Логическая согласованность

Объёмы отправленных и прибывших пассажиров должны сходиться с учётом явно заданных потерь.

## Перед запуском

Сценарий проходит предварительную проверку. Ошибки блокируют запуск, предупреждения видны пользователю.
