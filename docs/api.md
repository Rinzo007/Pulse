# API

API предоставляет предметные операции, а не только прямой доступ к таблицам.

## Группы

geography, network, stops, routes, schedules, fleet, demand, passengers, scenarios, simulations, kpis.

## Долгие операции

Генерация города, расчёт спроса и запуск симуляции выполняются как фоновые задачи с идентификатором запуска.

API возвращает состояние операции, диагностические ошибки и ссылки на результаты.
