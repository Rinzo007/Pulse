# 21. Дорожная карта

> Дорожная карта описывает порядок реализации Pulse. Она не переопределяет границы MVP из P1.4 и P2.5.

| Этап | Содержание | Выход |
|---|---|---|
| **M0. Модель и контракты** | P0.1–P0.5, единый registry констант, валидаторы city package/save | Воспроизводимое ядро Pulse Standard |
| **M1. Симуляция** | Demand → distribution → routing → mode choice → capacity/crowding → economics | Полный расчёт игрового года |
| **M2. Редактор сети** | Остановки, платформы, сегменты, маршруты, сервис, расписания, Undo/Redo, validator | Редактируемая сеть без отдельного строительного режима |
| **M3. Игровой слой** | Цели, запросы города, Sandbox/Scenario/Real Network, обратная связь с референсом | Игровой вертикальный срез |
| **M4. Первый город** | City Package, карта, reference network, quality report, эталонные сценарии | Первый полностью валидированный город |
| **M5. UX и стабильность** | Онбординг, accessibility, диагностика, save/migration, performance benchmarks | MVP |
| **M6. Beta** | Несколько городов, расширенные сценарии, пользовательские city packages, benchmark suite | Beta |
| **M7. 1.0** | Стабильный modding API, расширенные миграции, release-grade regression suite | Release 1.0 |
| **Post-1.0** | Онлайн-обмен, публикация пользовательских городов, лидерборды, кооперативные сценарии | Дополнительный online layer |
