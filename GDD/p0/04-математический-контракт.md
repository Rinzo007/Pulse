# P0.4 — Математический контракт

## Цель
Все расчётные величины имеют одну объявленную единицу измерения и источник константы.

## Канонические единицы
| Величина | Единица |
|---|---|
| расстояние | km |
| время | min |
| скорость | km/h |
| интервал | min |
| пассажиры | passenger/day или passenger/trip — всегда явно |
| деньги | валюта пакета |
| доля | 0–1 |
| процент | 0–100 |
| VOT | валюта/min |
| плотность | passenger/m² |
| вместимость | passenger |

## Правила формул
1. Каждое слагаемое имеет одинаковую размерность с результатом.
2. Коэффициент безразмерен, если иное не объявлено.
3. Константа хранится один раз в реестре модели.
4. В формуле указывается источник константы.
5. Преобразование единиц выполняется до расчёта, а не внутри случайных подсистем.

## Профиль модели
**Pulse Standard** — единственный нормативный runtime-профиль модели.

Все расчёты, сохранения и эталонные результаты используют один и тот же профиль. Исследовательские или совместимые коэффициенты не являются отдельными runtime-профилями; если они понадобятся, они должны быть явно версионированы как новая версия модели.

## Обязательные тесты
Для каждой формулы:
- размерностный тест;
- нулевое значение;
- минимальное и максимальное допустимое значение;
- монотонность там, где она физически ожидается;
- пример с известным результатом.

## Реестр констант
Константа имеет ID, значение, единицу, источник, профиль и версию.

```json
{
  "id": "mode.wait.headway_multiplier",
  "value": 0.40,
  "unit": "dimensionless",
  "source": "W26|SB",
  "profile": "pulse-standard",
  "version": 1
}
```

## Запрет
Нельзя добавлять числовую константу непосредственно в формулу без записи в реестре.
