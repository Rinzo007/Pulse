# P0.1 — Контракт качества модели

## Назначение
Единый нормативный контракт для проверки эталонного сценария города. Все разделы GDD должны ссылаться на этот документ, а не задавать собственные пороги.

## Статусы
- **PASS** — все применимые обязательные гейты пройдены.
- **WARN** — обязательные данные недостаточны для полного гейта, но модель пригодна только для исследовательского режима.
- **FAIL** — хотя бы один применимый обязательный гейт не пройден.
- **NO_DATA** — наблюдений недостаточно для расчёта показателя.

## Метрики
| Метрика | Определение | Основной гейт |
|---|---|---:|
| Суммарный пассажиропоток | `100 × (pred-fact)/fact` | ≤ ±15% |
| Pearson r | корреляция пар наблюдение/модель | ≥ 0.90 |
| Нормированный RMSE | `sqrt(mean(((pred-fact)/fact)^2))` по fact>0 | ≤ 0.30 |
| GEH | `sqrt(2(pred-fact)^2/(pred+fact))` | ≥85% наблюдений ≤5 |
| Доля поездок | `pred/fact` по доступным системам | ±10% |
| Удовлетворённость | разница модель/эталон | ≤5 п.п. |

### Мягкая зона
Pearson r 0.85–0.90 = **WARN**, а не PASS. Значение <0.85 = FAIL.

### Применимость
GEH и линейная корреляция считаются только при наличии достаточного числа сопоставимых наблюдений. Минимум для линейного сравнения — 20 наблюдаемых объектов. При меньшем количестве показатель = NO_DATA.

## Правила данных
1. Сравниваются одинаковые календарные периоды и одинаковые единицы.
2. Ноль факта не включается в относительную ошибку и RMSE.
3. Отсутствующее наблюдение не считается нулём.
4. Каждый показатель хранит источник, дату, период и уровень агрегации.
5. Нельзя смешивать посадки, пассажиров и поездки.
6. Если источник публикует только агрегат, точечные метрики не подменяются искусственно распределёнными значениями.

## Итоговый гейт
Город получает PASS только если все обязательные применимые метрики PASS. NO_DATA не может автоматически стать PASS; такой город получает WARN/неполный калибровочный статус.

## Формат отчёта
```json
{
  "model_version": "...",
  "city_package_version": "...",
  "scenario_id": "...",
  "status": "PASS|WARN|FAIL|NO_DATA",
  "metrics": {},
  "data_quality": {},
  "generated_at": "..."
}
```

## Источник
Пороговые значения наследуются из §12 GDD; данный документ устраняет конфликт между основным порогом r≥0.85 и более строгим ориентиром r≥0.90: 0.90 — рабочий PASS, 0.85–0.90 — WARN.
