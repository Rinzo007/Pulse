# P0.5 — Формат сохранения и миграции

## Формат
Основной файл сохранения: `.wkrt`.

Каждое сохранение содержит:
- `format_version`;
- `city_uid`;
- `city_package_version`;
- `model_version`;
- `state_hash`;
- состояние сети;
- расписания;
- парк и экономику;
- цели и прогресс;
- настройки;
- последний успешный годовой отчёт;
- историю миграций.

## Принцип
Сохранение должно быть самодостаточным для восстановления состояния игры. Внешний пакет города идентифицируется версией и не перезаписывается сохранением.

## Атомарная запись
1. записать во временный файл;
2. проверить структуру и контрольную сумму;
3. синхронизировать;
4. заменить основной файл атомарно;
5. оставить предыдущую рабочую копию до успешного открытия нового файла.

## Повреждение
Если контрольная сумма не сходится:
- основной файл не изменяется;
- предлагается последняя автоматическая копия;
- ошибка содержит причину и версию формата.

## Миграции
Миграции последовательные: `v1 → v2 → v3`. Прямые миграции через несколько версий не обязательны.

Каждая миграция:
- детерминирована;
- обратимо документируется;
- не удаляет неизвестные поля без правила;
- создаёт резервную копию до записи.

## Несовместимость
Если версия сохранения новее поддерживаемой — файл открывается только для чтения/выдаёт понятное сообщение; исходник не изменяется.

Если пакет города отсутствует или несовместим:
- сохранение не изменяется;
- пользователь получает идентификатор требуемого пакета;
- режим восстановления не подменяет данные молча.

## Проверки
Обязательные тесты:
- пустое сохранение;
- максимальное сохранение;
- повреждённый файл;
- обрезанный файл;
- неизвестная версия;
- миграция каждой поддерживаемой версии;
- повторное сохранение после миграции;
- сохранение после отменённого расчёта.

## Версионирование модели
Изменение коэффициентов или алгоритма повышает `model_version`. Старое сохранение не считается рассчитанным новой моделью до явного пересчёта.
