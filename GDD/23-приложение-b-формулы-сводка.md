# Приложение B. Формулы (сводка)

> **Статус:** справочная запись формул. Нормативные единицы, профили и числовые константы определяются P0.4. Числа в этой сводке не являются вторым runtime-реестром; реализация обязана получать константы из единого registry.

```
// ── Спрос ────────────────────────────────────────────────────────────────

// Распределение поездок: энтропийная модель, [Я22] ф.(2)-(4)
// maximise Σ_ij x_ij · ln(p_ij / x_ij)
// при Σ_j x_ij = A_i,  Σ_i x_ij = B_j,  x_ij ≥ 0

// Гравитационная форма (частный случай), [Я22] ф.(5)
F_ij = k · Q_i · Z_j · P_ij

// Функция предпочтения (калибруется по слоям), спецификация [Р]
P_ij = exp( −β_stratum · ln(1 + c_ij / t0) )
β по умолчанию: мегаполис 1.15 · крупный 1.05 · средний 0.95;  t0 = 15 мин

// ── Затраты пассажира ─────────────────────────────────────────────────────

// Режим A «Профессиональный», [Я22]: 6 компонентов, JRT = 1, остальные = 2
C = 2·(t_access + t_wait + t_transfer + t_walk_transfer) + 1·t_JRT + fare/VOT

// Режим B «Исследовательский», [W26] + [СБ]
PT = 1.00·t_ride + 1.39·t_walk + 1.37·t_wait + 0.40·t_shift + fare/VOT
M_headway(H) = 0.86 × (H/5)^(−0.44)      // 0.86 на 5 мин → 0.29 на 60 мин

// Режим C «Совместимость с Takt» (текущий движок репозитория), минуты
we = 405 + 0.25·метры + метры/1.33
Ge = 1 / max(1, cost)

// Авто (парковочный член — по зональному тарифу §12.5.2а, не плоская ставка)
PT_auto = 1.33·t_drive_congested + 1.60·t_parking(zone_tariff) + (km×0.65 + 5)/VOT

// ── Выбор режима (логит), [H20] ───────────────────────────────────────────
logit(P_auto) = 0.026·Δt_min + 0.510·ln(t_PT/t_auto) + 0.217·[пересадок>1]
              + 0.078·log10(walk_access) + 0.473·log10(walk_transfer)
              + 0.328·log10(walk_egress) + f_age + f_income

// ── Выбор режима (русская спецификация), [ДК23] ─────────────────────────────
U_авто = 2.50 − 0.5·CT − 0.010·TT
U_ОТ   =      − 0.4·CT − 0.012·TT
P_авто = e^U_авто / (e^U_авто + e^U_ОТ)      // CT — стоимость, TT — время

// ── Эластичности рычагов, [ДК23] ────────────────────────────────────────────
// тариф ОТ пик −0.18/−0.27; внепик −0.39/−0.46; парковка −0.08;
// бензин краткоср. −0.15, долгоср. −0.60

// ── Доступность (Хансен 1959), [ДК23] ───────────────────────────────────────
A = Σ_j (x_j · f(d_ij)),   напр. F_ij = 1/t_ij^α, α ≈ 2.0
// logsum-выигрыш:  A = ln(Σ_c exp(V(c)))   (Anas 1983: ≡ гравитации)
// Пороги: 15 мин = 4 км, 30 мин = 8 км, 45 мин = 12 км; пешком 15 мин = 1 км

// ── Удовлетворённость и качество ──────────────────────────────────────────
Satisfied = Σ served·max(0, 1 − Σ penalties) / Σ reachable

// Средняя поездка — основной интегральный показатель, [Я22] ф.(6)
t_cp = Σ_ij (t_ij · x_ij) / Σ_ij x_ij
     где t_ij = средневзвешенное по путям k:  t_ij = Σ_k (t_kij · x_kij) / Σ_k x_kij

// Среднее время поездки на ОТ, [Я22] ф.(8)
T_ОТ = T_поездки + T_пересадки + T_пеш_пересадки + T_нач_подход + T_кон_подход
     + κ_пересадки · T_поездки

// Эффект минуты (рублей на минуту) — метрика ценности проекта, [Я22]
effect_per_min = стоимость_сценария / Δ t_cp

// ── Зональная обеспеченность, [ТЯ22] ─────────────────────────────────────────
// TOT = Σ(x_CD·l·t)/Σ(x_CD·l)   — внутренние корреспонденции зоны
// TOD = Σ(x_BC·l·t)/Σ(x_BC·l)   — пограничные (въезд/выезд)
// TOTR = Σ(x_AB·l·t)/Σ(x_AB·l)  — транзитные
// THcpi = 0·TOTRi + 0.3·TODi + 0.7·TOTi ;  THcp = Σ(αi·THcpi), αi = Si/ΣSj
// WP = THcp / VP   (мин/руб) — ранжирование проектов: в план идёт max WP
// Gr = ΣΣ(k_ij·l_ij) — транспортная зависимость; kHT/kOT — качество планирования

// ── Маршрутизация, [R11] ───────────────────────────────────────────────────
// Сложность:  O( K · (Σ_{r∈R}|r| + |T| + |F|) )
// Шаг 15 (target pruning, строгое неравенство — обработка ничьих):
//   если arr(t,p_i) < min{τ*(p_i), τ*(p_t)} то пометить p_i
// Шаг 6 (возврат первого этапа в rRAPTOR):
//   τ_k(p) ← τ_{k−1}(p) для всех p, где τ_{k−1}(p) улучшает τ_k(p)
// Батчинг: группировка (origin_stop, window_30min) → один onetomany-вызов [ТР]
// Инварианты загрузки: сортировка трипов; транзитивное замыкание footpaths;
//   FIFO (удалить обгоняющий ранний рейс); удалить solo-routes и дубли [ТР]

// ── Строительство и эксплуатация ───────────────────────────────────────────
cost = base_rate[mode][level] · km · mult_lanes · mult_obstacle
     · mult_water · city_index

// Себестоимость км по НМЦК, [НМ25]
S_km = (ФОТ + страховые + топливо + ремонт + инфраструктура
      + диспетчеризация + депо + прочие) / K_исп
Ц_км = S_km × 1.1107 + РП_на_км          // R = 1.1107 [НМ25]

// Размер парка линии, [МР21] + [НМ25]
fleet = ceil( (2 × (Σride + Σdwell + turnaround) / headway_peak) / K_в )
// K_в: 0.85 автобус, 0.9 ГЭТ [НМ25]

// Ограничение провозной способности ОТ (функция SBB), [Я22]
// a = 0, b = 3, c = 2, l1 = 1, l2 = 2

// Скорость в кривой (супервозвышение), [СБ]; 1 м/с² ≡ 150 мм
v = √( (cant + deficiency) / 150 · radius )
```
