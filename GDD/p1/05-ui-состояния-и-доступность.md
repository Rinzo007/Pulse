# P1.5 — UI-состояния и доступность

## Состояния
Каждый экран/панель поддерживает:
- loading;
- ready;
- empty;
- warning;
- error;
- disabled;
- calculating;
- cancelled.

## Основные взаимодействия
Поддерживаются поиск, выбор, множественный выбор, панель свойств, контекстные действия, Undo/Redo и горячие клавиши.

## Цвет
Критическая информация не кодируется только цветом. Каждый цветовой сигнал имеет текстовый, значковый или числовой эквивалент.

## Клавиатура
Обязательные операции:
- навигация по карте;
- поиск;
- выбор;
- открытие свойств;
- изменение значения;
- запуск проверки;
- запуск расчёта;
- Undo/Redo;
- сохранение.

## Разрушительные операции
Удаление и массовые изменения требуют подтверждения либо обратимы через Undo.

## Ошибки
Ошибка показывает:
1. что произошло;
2. какой объект затронут;
3. почему операция невозможна;
4. что пользователь может сделать дальше.
