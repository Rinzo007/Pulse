# P2.5 — Матрица релизов

## MVP
- один реальный город;
- полный расчёт года;
- редактор базовой сети;
- спрос и маршрутизация;
- экономика;
- цели;
- сохранение;
- офлайн-работа;
- базовый отчёт качества.

## Beta
Добавляются:
- несколько городов;
- расширенные сценарии;
- benchmark suite;
- пользовательские пакеты;
- улучшенная доступность;
- диагностические отчёты.

## 1.0
Добавляются:
- стабильный формат моддинга;
- расширенные городские сценарии;
- полноценная миграция пакетов;
- полированный UI;
- release-grade regression suite.

## Post-1.0
Кандидаты:
- онлайн-обмен;
- публикация пользовательских городов;
- лидерборды;
- совместные сценарии.

Ни одна post-1.0 возможность не должна быть обязательной зависимостью основного симулятора.
