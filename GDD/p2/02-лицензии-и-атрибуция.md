# P2.2 — Лицензии и атрибуция

## Обязательный provenance
Для каждого внешнего набора данных фиксируются:
- источник;
- дата получения;
- лицензия;
- версия;
- преобразования;
- checksum при необходимости.

## Игровые данные
Каждый пакет города содержит собственный блок attribution и license.

## Код и библиотеки
Перед релизом формируется inventory зависимостей с лицензиями. Несовместимые с распространением лицензии блокируют релиз до ручной проверки.

## UI
Атрибуция должна быть доступна из экрана сведений о городе/пакете и из общего раздела Credits/Legal.

## Правило
Нельзя распространять внешний датасет или его производное представление без проверки условий исходной лицензии.
