# Приложение A. Глоссарий

| Термин | Определение |
|---|---|
| **Takt** | Интервал между двумя единицами транспорта на линии, минуты |
| **Посадка (boarding)** | Один пассажир, севший в единицу транспорта. Поездка с пересадкой = несколько посадок |
| **Поездка (trip)** | Полный путь одного человека от начала до цели. Считается один раз, даже с пересадками |
| **Пассажиро-км** | Пассажир × километр. Один пассажир, проехавший 5 км, добавляет 5 |
| **Транспортная плотность** | Пассажиро-км в сутки ÷ длина линии. Не то же, что заполненность |
| **Fares cover** | Доля эксплуатационных затрат, покрываемая тарифами. Норма 1/3–3/4 |
| **Subsidy per rider** | Дотация на одного пассажира. Норма ≈ €0.30 |
| **Обобщённое время** | Сумма времени по компонентам с весами восприятия |
| **Headway-мультипликатор** | Вес ожидания; зависит от интервала (0.86 на 5 мин → 0.29 на 60 мин) |
| **Парето-маршрут** | Маршрут, не уступающий другому ни по времени, ни по числу пересадок |
| **Раунд (rRAPTOR)** | Итерация, соответствующая одной пересадке |
| **Demand point** | Точка с населением и рабочими местами |
| **Pop** | Группа поездок: размер, дом, работа |
| **Walk reach** | Доля поездок, у которых остановка в пешем охвате начала или конца |
| **Award** | Постоянная награда за долю городских поездок |
| **Sandbox** | Режим без лимита строительного бюджета |
| **Слой спроса (stratum)** | Пара «откуда–куда» по типам объектов (дом, работа, учёба, прочие). Норма: ≥8, полный набор 15 = 4²−1 `[Я22]` |
| **Матрица корреспонденций (OD)** | Таблица объёмов поездок между парами районов |
| **Функция предпочтения** | Вероятность поездки в зависимости от затрат. Единственный калибруемый элемент распределения `[Я22]` |
| **Эквифинальность** | Гравитационный, энтропийный подходы и метод итоговых коэффициентов дают одинаковый результат `[Я22]` |
| **JRT** | Время движения внутри подвижного состава — единственный компонент с весом **1** в отраслевой норме `[Я22]` |
| **Матрица затрат (skim)** | Обобщённая стоимость поездки между парами районов по каждому компоненту отдельно `[Я22]` |
| **Коэффициент корреляции модели** | Порог качества ≥ **0.85** по требованиям Методических рекомендаций Минтранса `[Я22]` |
| **Среднеквадратичное отклонение (MSE)** | Порог качества ≤ **0.3** `[Я22]` |
| **Район-кордон** | Транспортный район на границе агломерации — отдельная калибровочная сущность `[Я22]` |
| **CDR-геоаналитика** | Определение местоположения абонентов по детальным записям вызовов. Сетка 500 м, разбивка 1.5 ч `[Я22]` |
