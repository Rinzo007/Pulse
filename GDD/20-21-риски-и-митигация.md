# 21. Риски и митигация

| # | Риск | Вероятность | Влияние | Митигация |
|---|---|---|---|---|
| R1 | **Модель слишком сложна, игрок не видит причинно-следственных связей** | Высокая | Критическое | P2/P3; слой «ожидаемое изменение»; онбординг-метрика «время до осмысленного решения» |
| R2 | **Год слишком долог** (потеря темпа) | Средняя | Высокое | Быстрый первый год; пресеты takt; Sandbox; переключатель темпа |
| R3 | **Год слишком короток** (нет ощущения развития) | Средняя | Среднее | Накопительные awards, история по годам, персистентные песочницы |
| R4 | **Расхождение модели с реальностью** (потеря доверия) | Средняя | Критическое | P6: проверка в каждом городе, гейт §12.4, честная маркировка «вне калибровки» |
| R5 | **Производительность на крупных городах** | Высокая | Высокое | Бинарный индекс зданий (×20 экономии) `[СБ]`; rRAPTOR `[R11]` (7.3 мс на Лондоне, 16–24 мс на ЛА/Нью-Йорке); бюджеты §8.5; LOD через `buildingZoomOffset`; отключение 3D-зданий `[СБ]` |
| R6 | **Данные недоступны для конкретного города** (нет переписи или GTFS) | Средняя | Высокое | Модельная генерация с пометкой «оценка»; гейт не пропускает город без сверки |
| R7 | **Копирование дизайна конкурентом** | Средняя | Среднее | Отстройка через P6, через подгруппы из `[H20]` (никто не делает), через ценообразование по режимам |
| R8 | **Моддинг-контент низкого качества** | Высокая | Низкое | Калибровочный гейт, рейтинг, отзывы |
| R9 | **Юридические риски данных** (OSM ODbL, GTFS, аэрофото) | Средняя | Высокое | Строгая атрибуция; `[П]` явно лицензирует свои demand-файлы только для игры; проверка лицензий аэрофото по городам |
| R10 | **Выгорание разработчика** (оба референса — игры одного человека) | Высокая | Критическое | Архитектура «данные отдельно от кода» позволяет масштабировать команду; моддинг-API как рычаг; приоритет P7 против feature-bloat |
| R11 | **Нет отраслевых эталонов для сверки вне Европы/США** (даже при наличии сырых данных не с чем сравнить калибровку) | Высокая | Высокое | Для российских городов риск снят: есть отраслевая откалиброванная модель `[Я22]` (§12.5). Для остальных — пометка «оценка по модели», расширенный коридор допуска и обязательная сверка с локальными счётчиками; город не выходит в релиз без сверки (§12.4) |

**Возрастной рейтинг:** 12+ (тема денег, пробок, последствий решений; насилия нет).
